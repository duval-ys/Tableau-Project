# Tableau-Project
To develop and design a comprehensive dashboard that analyzes superstore sales performance (YOY).

## Dataset used
<a href="https://github.com/duval-ys/Tableau-Project/blob/main/RAW%20DATA.csv">dataset</a>

## KPI questions
	What is the total sales revenue for the current year compared to the previous year?

	What is the average order value over the Years?

	What is the YoY growth rate in sales revenue?

	What is the YoY change in the number of orders placed?
